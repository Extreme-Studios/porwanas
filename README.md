# PORWANAS

Portal informasi Pekan Olahraga Wartawan Nasional, dibuat dengan Next.js dan Tailwind CSS.

## Menjalankan lokal

1. Salin `.env.example` menjadi `.env.local`.
2. Isi `NEXT_PUBLIC_REGISTRATION_FORM_URL` dengan URL Google Form resmi.
3. Jalankan `npm install`, lalu `npm run dev`.

Konten dummy berada di `src/lib/data.ts` agar mudah diganti.
